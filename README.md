# SeeItOn - Virtual Try-On Mobile Application

SeeItOn, kullanıcıların seçtikleri kıyafetleri kendi fotoğrafları üzerinde saniyeler içinde fotogerçekçi bir şekilde denemelerini sağlayan yapay zeka destekli (IDM-VTON) bir mobil uygulamadır.

## Teknolojiler
* **Mobil:** Flutter
* **Backend:** FastAPI (Python)
* **Veritabanı & Auth:** Supabase
* **Yapay Zeka:** IDM-VTON (Diffusion Model)

# Kayıt / Giriş Akışı — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Supabase e-posta/şifre ile gerçek kayıt-giriş, oturum hatırlama, çıkış ve iki dilli hata mesajları.

**Architecture:** `AuthGate` uygulamanın kökünde Supabase oturum akışını dinler ve ana ekran / tanıtım ekranı arasında seçim yapar. Giriş ve çıkış yalnızca oturumu değiştirir ve üstteki rotaları kapatır; kök ekranı AuthGate değiştirir. Hata metinleri saf bir eşleme fonksiyonuyla ARB anahtarlarına çevrilir.

**Tech Stack:** Flutter, `supabase_flutter` 1.10 (gotrue 1.12), gen-l10n, `flutter_test`.

**Spec:** `docs/superpowers/specs/2026-11-04-auth-design.md`

## Global Constraints
- Komutlar `see_it_on/` içinden; Flutter: `C:\src\flutter\bin\flutter.bat`.
- E-posta doğrulaması yok; şifre alt sınırı **6** karakter.
- Tüm yeni metinler `lib/l10n/app_tr.arb` + `app_en.arb`; ekranlarda sabit metin yok.
- Hatalar SnackBar ile (mevcut `_showError` stili).
- Debug "Girişi atla" butonu kalır (yalnızca `kDebugMode`).
- `await` sonrası `context` kullanımı `mounted` kontrollü. `flutter analyze` temiz, `flutter test` geçer.

## Review Focus
- Ağ yokken giriş → çökme yok, "İnternet bağlantısı yok / No internet connection" mesajı. Task 1'de `authErrorMessage(l, ClientException('x'))` testi.
- E-posta başında/sonunda boşluk → kırpılıp kabul edilir. Task 1'de `isValidEmail('  a@b.co  '.trim())` + giriş ekranı `trim()` kullanır (mevcut).
- Çıkıştan sonra geri tuşu → ana ekrana dönmemeli. Task 2'de AuthGate testi: oturum kapanınca `HomeScreen` ağaçta yok.
- Giriş isteği sürerken ekrandan çıkılırsa → dispose edilmiş context'e SnackBar yok. Task 3'te `on AuthException` dalı `mounted` kontrollü (inceleme bulgusu).
- Oturum açıkken uygulama yeniden açılır → tanıtım ekranı görünmeden ana ekran. Task 2'de "başlangıçta oturum var → HomeScreen" testi.
